Request Data Flow

1

Server Startup

mock_data.py reads all JSON files into Python lists held in memory. Data persists only while the server process runs.

load_json_file('inventory.json')
2

User Interaction

User navigates to a view (e.g., /inventory) or changes a filter. Vue Router renders the matching view component.

3

Filter State

The view reads global filter state from the useFilters composable (singleton refs) — warehouse, category, period, status.

useFilters().getCurrentFilters()
4

API Call

The view calls api.js which sends an Axios GET request with filter values as query params to the FastAPI backend.

GET /api/inventory?warehouse=SF
5

Backend Filtering

FastAPI applies apply_filters() and filter_by_month() to the in-memory list, then serializes results through Pydantic models.

6

Render

JSON response stored in a Vue ref. Computed properties derive summary values. Vue re-renders the table / charts reactively.

items.value = response.data

Key Constraints & Gotchas

No Persistence

In-Memory Only

All data lives in Python process memory. Any writes (tasks, purchase orders) are lost on server restart. JSON files are read-only sources.

Filter Scope

Inventory Has No Month

The inventory endpoint does not support month/period filtering — stock levels have no time dimension. Only warehouse and category apply.

Revenue Targets

$800K/mo · $9.6M YTD

Dashboard revenue goals are hardcoded: $800K for a single month, $9.6M year-to-date when all months are shown.
